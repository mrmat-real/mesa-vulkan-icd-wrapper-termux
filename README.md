# mesa-vulkan-icd-wraper
A beautiful package that allows mali gpus to run vulkan in termux. It disappeared from official repositories and i found a zip file from someone with this very package. On a mali g57 mc3 with vulkan 1.1.777 in supertuxkart on ravenbridge mansion with 3 bots and low settings i got 35-50 fps with a few artifacts at 1080p with 50% scaling
